## 复杂度

### 定义

复杂度是衡量算法运行时所需时间与内存资源消耗的指标。通过复杂度分析可以衡量算法的效率，进而改进算法，提高代码运行效率。

### 分类

包括两类，时间复杂度与空间复杂度。

**时间复杂度**(asymptotic time  complexity)，表示算法的执行时间与数据规模之间的增长关系.

**空间复杂度**(asymptotic space complexity)，表示算法的存储空间与数据规模之间的增长关系。

## 时间复杂度

### 引入

#### **基本操作数**

顾名思义，计算机的一次操作，在底层是硬件上的行为，往上是语言的一条简单语句，包括加减乘除、访问变量、赋值等等，不同操作类型耗时也有差别。

在算法分析当中，抓大放小，可以将基本操作的时间差异忽略。

#### 渐进符号

下面只是一个介绍，算法中常用的是大O，表示渐进上界

**Θ（Theta，渐近紧确界）**

Θ 表示函数的渐近紧确界，即函数的增长速度与某个参考函数相同。数学定义为：存在常数$ c_1、c_2 $和 $n_0，使得对于所有$$ n \geq n_0$，有 $c_1g(n) \leq f（n) \leq c_2g(n)$。例如，若 $T(n) = 30n^4 + 20n^3$，则 $T(n) = Θ(n^4)$。

**O（Big-O，大 O，渐近上界）**

O 表示函数的渐近上界，用于描述算法的最坏情况复杂度。数学定义为：存在常数$ c和 n_0$，使得对于所有$ n \geq n_0，有 f(n) \leq c \cdot g(n)$。例如，若$ f(n) = n^2 + n，则 f(n) = O(n^2)。$

**Ω（Omega，大 Ω，渐近下界）**

Ω 表示函数的渐近下界，用于描述算法的最优情况复杂度。数学定义为：存在常数 $c 和 n_0$，使得对于所有$ n \geq n_0$，有 $f(n) \geq c \cdot g(n)$。例如，若 $f(n) = n^2 + n$，则 $f(n) = Ω(n^2)$。

**o（小 o，非紧确上界）**

o 表示函数的非紧确上界，即函数的增长速度严格小于某个参考函数。数学定义为：对于任意正数 $c$，存在 $n_0$，使得对于所有$ n \geq n_0$，有 $f(n) < c \cdot g(n)$。例如，若 $f(n) = n^2 + n$，则 $f(n) = o(n^3)$。

**ω（小 ω，非紧确下界）**

ω 表示函数的非紧确下界，即函数的增长速度严格大于某个参考函数。数学定义为：对于任意正数 $c$，存在 $n_0$，使得对于所有 $n \geq n_0$，有 $f(n) > c \cdot g(n)$。例如，若 $f(n) = n^2 + n$，则 $f(n) = ω(n)$。

### 渐进时间复杂度

在进行算法分析时， 语句总的执行次数 $T ( n )$ 是关于问题规模 $n $的 函 数 。进 而 分 析$ T ( n ) $随$ n $的变化情况并确定$ T ( n ) $的 数 量级。算法的时间复杂度，也就是算法的时间量度， 记作：$T ( n )= O(f(n))$。它表示随问题规模$ n $的增大， 算法执行时间的增长率和$f ( n ) $的增长率相同， 称作算法的渐近时间复杂度，

简而言之，它反映的是随着规模n的增大，时间的增长率。

### **分类**

**按复杂度的估算方式划分**

1. 最坏时间复杂度，考虑最极端的情况，每一次数据处理都对应最坏情况，很容易分析
2. 最好时间复杂度，最理想的情况下，执行代码的复杂度，一次成功那就是$O(1)$
3. 平均情况复杂度，简称平均复杂度
4. 均摊时间复杂度，简称均摊复杂度（分析方式为摊还分析或平摊分析）

**按复杂度量级划分**

多项式量级：常量阶$O(1)$，对数阶$O(log\ n)$，线性阶$O(n)$，线性对数阶$(nlog\ n)$，平方阶$O(n^2)$，立方阶$O(n^3)$

非多项式量级：指数阶$O(a^n)$，阶乘阶$O(n!)$

### P.S. 为什么$O(logn)$没有底数？

1. 很多算法实际上都跟“2”有关，对数底数其实就为2
2. 在渐进时间复杂度当中，由于大O反映的是增长率，通过换底公式将不同对数进行转换，可注意到增长速率只相差常数级（倍数），进行忽略，所以统一用$O(logn)$表示

## 递归时间复杂度

### 引入

$T(n)$是时间复杂度函数，$\Theta(n)$是紧确界。

$T(n)$，n为输入规模，如$T(n)=3n+5$. 在递归式当中，有如$T(n)=2T(\frac{n}{2})+n$



**$\Theta(n)$是什么？**

正式定义

$$f(n)=\Theta(g(n))$$，当且仅当存在正常数$c_1,c_2$和$n_0$，使得对所有$n\geq n_0$，有

​	$0\leq c_1g(n)\leq f(n) \leq c_2g(n)$	

 意思为，$f(n)$和$g(n)$的增长速度为同一个量级，只差常数倍

记	$T(n)=\Theta (n)$

eg.$T(n)=3n+5$

$T(n)=100n$

$T(n)=0.01n+1000$

tips:$\Theta(n)$为函数集合，不是一个具体的函数，更不是等于n，严格上是$T(n)∈Θ(n)$

### 主定理

主定理用于快速求解形如：

$T(n)=aT(n/b)+f(n),a≥1, b>1$

的递归式。令$c=log_ba$，比较$f(n)$和$n^c$的大小

**情况一：$f(n)$ 比 $n^c$ 小**

$T(n)=\Theta(n^c)$

**情况二：$f(n)$ 比 $n^c$ 同阶**

$T(n)=\Theta(n^clogn)$

更一般地，若$f(n)=Θ(n^clog⁡^kn)$，则：

$T(n)=Θ(n^clog⁡^{k+1}n)$

**情况三：$f(n)$ 比 $n^c$ 大**

若存在 $ε>0$，使：

$f(n)=Ω(n^c+ε)$

**并且满足正则条件：**

$af(\frac{n}{b})≤kf(n),0<k<1$

则：

$T(n)=\Theta(f(n))$
