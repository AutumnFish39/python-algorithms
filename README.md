## algorithms

该目录下为算法的知识体系，包括对算法的通用实现，复杂度分析及应用优缺点的记录

学习以《算法》（Robert Sedgewick, Kevin Wayne，第四版）为基础，后续会补充其他网站及书籍的算法

## data_structures

主要记录有特殊算法的数据结构，一些基础的工具类数据结构就不提及了。

## problems

为`algorithms`的补充题目，来源主要为`luogu`、`leetcode`。

分类取决于一道题目最主要（或最精彩）的解决方式，如果一个题目同时存在两个以上同等重要的算法，会在页面标注，并同时存放于两个算法目录之下。
